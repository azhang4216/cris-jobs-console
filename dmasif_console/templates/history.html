Start an experiment

From your repository to the GPU.

01—03
  1. Add the run configuration

    Save this as experiments/run.yaml in the approved research repository.

    schema_version: 1
job_type: dmasif_extract
dataset_id: demo-1stp-v1
preset_id: quick-test
seed: 0
repeat_id: first-run
  2. Commit and push a run branch

    Choose an experiment name and use your personal GitHub account. We record who pushed automatically.

    git switch -c runs/pocket-v1
git add experiments/run.yaml affinity/extract.py
git commit -m "Run pocket-v1 feature extraction"
git push -u origin HEAD
  3. Follow the run here

    One push runs its final commit. To repeat, change repeat_id, commit, and push again. Every push to a run branch can start work.

Branch names are shared. Use different experiment names for independent work; every run gets separate outputs.
